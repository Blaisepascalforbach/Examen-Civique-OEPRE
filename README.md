# Examen civique · CSP · Révision (version de test)

Outil de révision hors connexion : un seul fichier `index.html`.

- 191 questions de connaissance de la série CSP, publiées par le ministère de l'Intérieur.
- Les propositions de réponses ne sont PAS un corrigé officiel. Elles doivent être validées par un formateur avant tout usage. Les 35 propositions marquées « à confirmer » sont les plus fragiles.
- Interface en 11 langues : les traductions doivent être relues par des locuteurs. Les questions restent en français.

Ouvrir `index.html` dans un navigateur. Aucune donnée n'est envoyée : la progression et les remarques restent sur l'appareil.
